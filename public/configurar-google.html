Activar el acceso con Google

El ID público de Google ya está conectado en Acontec. El propietario solo necesita comprobar en Google que el dominio esté autorizado y que las cuentas de sus clientes puedan acceder. Los clientes no necesitan realizar esta configuración.

1. Abre tu cuenta de Google

Entra en Google Cloud Console. Selecciona un proyecto o crea uno con el nombre Acontec. Para este acceso no necesitas activar servicios de pago.

2. Configura la aplicación

Abre Google Auth Platform → Branding (o APIs y servicios → Pantalla de consentimiento de OAuth). Pulsa Comenzar si aparece. Escribe Acontec como nombre y selecciona tus correos de soporte y contacto.

En Audience / Público, selecciona Externo para permitir cuentas de tus clientes. Mientras esté en pruebas, agrega sus correos como usuarios de prueba. Para abrir el acceso a todos los clientes, cambia la aplicación a producción según las indicaciones de Google.

3. Revisa el cliente web existente

Abre Clients / Clientes (o APIs y servicios → Credenciales) y selecciona el cliente de tipo Aplicación web cuyo ID proporcionaste. No necesitas crear otro cliente.

En Orígenes autorizados de JavaScript, agrega exactamente este origen, sin rutas ni barra final:

https://zesty-donut-fecaa0.netlify.app

Si utilizas otro dominio o una vista previa, autoriza también su origen HTTPS. No necesitas configurar una URL de redirección para este flujo.

4. El ID público ya está conectado

Acontec utiliza el ID público que proporcionó el propietario. No necesitas guardar una variable en Netlify ni compartir el secreto del cliente.

Solo si cambias de cliente, abre el proyecto en Netlify y entra en Project configuration → Environment variables → Add a variable. Usa GOOGLE_CLIENT_ID como nombre y el nuevo ID público como valor. Selecciona el alcance Functions para los contextos que utilices y redespliega una sola vez.

5. Comprueba el acceso

Después del despliegue de esta actualización, abre el dominio autorizado y pulsa Continuar con Google. Si aparece un error de origen, revisa que el dominio coincida exactamente con el del paso 3. Guardar cambios de orígenes o público en Google no requiere otro despliegue de Acontec.

Tu acceso por correo ya no necesita claves manuales

En la pantalla de acceso, pulsa Crear cuenta, escribe tu correo, una contraseña de al menos ocho caracteres y el nombre de tu empresa. Abre el enlace de confirmación que recibas por correo. Después podrás entrar con esas credenciales y ver únicamente tus empresas.

No basta con escribir cualquier correo para entrar: se mantiene la verificación de identidad para proteger la contabilidad. Nunca compartas contraseñas ni secretos en un chat.

El botón de Google utiliza el ID público conectado y el servidor verifica la identidad antes de permitir el acceso. La autorización del dominio y del público se administra en Google, no desde esta página.
